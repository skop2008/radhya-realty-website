# Feature Planning Protocol (/plan-feature)

1. **Inspect Codebase**: Read relevant templates, styles, scripts, and server configuration.
2. **Identify Edge Cases**: Mobile viewports, offline state, latency, backward compatibility.
3. **Formulate Plan**: Write plan to `docs/plans/$ARGUMENTS.md` detailing exact edits, non-destructive guardrails, and verification steps.
4. **Pause for Confirmation**: Await user approval before touching more than two files simultaneously.
